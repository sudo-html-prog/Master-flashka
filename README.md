# Флешка мастера: приложение

Программа для Windows. Выбираете флешку с Ventoy, она скачивает образы прямо на неё и сверяет SHA-256.
Подключённый по кабелю телефон определяется через adb и fastboot.

## Как получить .exe без программирования (через GitHub)
1. Создайте на github.com новый репозиторий и загрузите в него все файлы из этой папки
   (включая скрытую папку `.github`).
2. Положите свой сайт «Флешка мастера» в `app/index.html`
   (он открывается кнопкой «Каталог моделей и прошивок»).
3. Откройте вкладку Actions, выберите workflow `build`, нажмите Run workflow.
4. Через 3-5 минут внизу страницы запуска скачайте `Flashka-exe`. Внутри лежит `.exe`.
5. Положите `.exe` в корень флешки, на ПК запускайте двойным щелчком.

## Не проверено
Код написан без запуска (в среде не было интернета и Windows). Если сборка упадёт, пришлите текст ошибки из Actions.

## Ограничения
- Windows и многие другие образы нельзя скачать напрямую: открывается официальная страница.
- Прошивать можно только модели, для которых прошивка существует. Для Samsung A25 5G кастомной прошивки в каталоге нет.
